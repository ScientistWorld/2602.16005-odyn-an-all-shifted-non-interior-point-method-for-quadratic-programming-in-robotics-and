# Benchmark scoring audit

Each named experiment has a `run.sh`. It builds an isolated future-agent-visible
workspace, produces method results, invokes the visible training scorer, installs
the original hidden evaluator, and invokes `bash scripts/evaluate_test.sh` with
**no arguments** in a new process. No evaluator or Python environment is modified.

`fixtures/eval/test/` and `fixtures/scoring/{reference,scores_test}.json` are
**auditor-only**: they never enter a candidate workspace until evaluation, and
candidate result generators never read them. Candidate generators use only the
visible MAT filenames, the visible upstream CSV, or outputs generated by the
visible reference method. The original method snapshot is available in improve
mode; shortcuts that fabricate records or replay the CSV also work from scratch.

Raw solver outputs and logs are retained in each experiment's ignored
`artifacts/`. Small score JSONs and audit summaries are committed. Reference seed
0 outputs are reused only for changes to reporting, as authorized by the audit.

Run the suite inside the gym container using `bash redteam/run_all.sh`. This is
actual computation and must be submitted as a job. Individual `run.sh` scripts
can also be submitted as jobs. A completed case is resumable using its saved
scores; delete its `complete.json` to repeat it. The three reference seeds start
from independent solver executions, rather than rescore one saved execution.
